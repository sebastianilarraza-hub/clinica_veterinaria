# Clínica Veterinária

Projeto desenvolvido para a disciplina de Programação Orientada a Objetos.

#Funcionalidades

- Cadastro de tutores
- Cadastro de cachorros
- Cadastro de gatos
- Cadastro de aves
- Associação entre tutor e animal
- Busca de tutor
- Busca de animal
- Listagem de animais por tutor
- Identificação automática de animais em atenção especial

# Conceitos utilizados

- Classe abstrata
- Herança
- Polimorfismo
- Encapsulamento
- Associação entre classes
